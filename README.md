# ReadmeAI

AI-powered README generator. Paste a GitHub repo URL, it reads every file, estimates token cost, gets your confirmation, then generates and pushes a professional README directly to your repo.

## Stack
- FastAPI + PostgreSQL + Redis — backend
- Docker Compose — local orchestration
- OpenAI GPT-4o-mini — generation
- Next.js — frontend (coming soon)
